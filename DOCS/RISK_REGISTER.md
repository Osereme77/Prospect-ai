## Review rules

- Revisit the register after a new provider, environment, permission boundary, scheduled job, or production release is introduced.
- A risk closes only when its stated evidence exists; code presence, a local mock, or a green unrelated CI job is insufficient.
- Keep source discovery, email delivery, and schedules disabled whenever their permission, ownership, quota, sender, or recovery controls are unresolved.
- Never place service-role credentials, provider secrets, recovery links, or access tokens in this file or any other tracked file.
